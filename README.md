# Nest Zod Template

A lightweight and extensible NestJS template using [Zod](https://zod.dev/) for schema validation via custom global pipes.  
Includes metadata-based validation strategy, ideal for scalable API projects.

## Features

- 🧩 Global Zod validation pipe
- ✅ Decorator-based schema registration
- 🧪 DTO & schema separation pattern
- 🔁 Ready for extension with Swagger, Guards, and Middleware
